2. $What{-}if$ Bench: 基准构建与多维评估框架为了突破现有评测在宏观反事实推演上的局限性，并解决大语言模型评估中普遍存在的“文本遮蔽效应”（Text Masking Effect），我们提出了 $What{-}if$ Bench。该基准不仅提供了一个高质量的反事实问题集，更引入了一套创新的动态解耦评估流水线（Dynamic Decoupled Evaluation Pipeline），将模型的隐式推理过程显式化、结构化。2.1 基准数据集构建 (Benchmark Construction)$What{-}if$ Bench 经过严格筛选与校验，最终包含 150 道高质量的反事实因果推演条目（Items）。为了全面检验大模型的泛化推理能力，这些条目在设计上遵循两个核心分类维度：跨学科领域 (Domain): 涵盖了 STEM（科学、技术、工程、数学）与 HASS（人文、艺术、社会科学）两大领域。这要求模型不仅能处理遵循严格物理定律的反事实推演（例如：“如果你试图去打一个以 90% 光速投出的棒球会发生什么？”），还能处理涉及复杂社会网络、历史走向的开放性人文推演。问题收敛性 (Question Type): 将问题划分为 Closed（封闭式） 与 Open（开放式） 两类。封闭式问题通常具有明确的因果推演终点或客观真值（Ground Truth, GT）；而开放式问题则指向发散性的宏观演变，不存在绝对唯一的结局，更侧重于推演过程的合理性。所有问题均经过人工标注，确保其具备“可解析性”（Parsability）。2.2 评估体系设计 (Evaluation Framework)针对开放域问题“真值难定”的痛点，我们摒弃了传统“一刀切”的比对评测，提出了一套条件自适应的多维评估公式：对于开放式问题 (Open Items): $\text{Metrics} = \text{PM} + \text{RM}$对于封闭式问题 (Closed Items): $\text{Metrics} = \text{PM} + \text{RM} + \text{OM}$该框架由以下三个核心评估模块（PM, RM, OM）构成：1. 过程评估指标 (PM: Process Metric) —— 结构化逻辑严谨度校验这是本框架打破“逻辑幻觉”的核心创新。我们确立了“文本 $\rightarrow$ 结构 $\rightarrow$ 校验”的两阶段解析范式：图谱解析 (Parser Model): 首先，利用解析模型（Parser Model）将大语言模型生成的隐式、长篇幅自然语言回复（LLM Response）抽取并转换为有向无环图（DAG）。边级校验 (Edge-level Verification): 针对图中提取出的因果链路（即节点 $V_i$ 到 $V_j$ 的边），我们引入 “RAG + Judge LLM” 机制。检索增强生成（RAG）为判断提供外部事实与公理支撑，Judge LLM 则专门聚焦于评估 $V_i \rightarrow V_j$ 这一局部推演的“过程严谨度”。这种微观切片式的评估，彻底阻断了模型用流畅辞藻掩盖推理断层的可能。2. 量表评估指标 (RM: Rubrics Metric) —— 文本维度的专家级定性除了结构化的骨架提取，我们依然保留了对原始文本回复的整体质感评估。通过精心设计的 Rubrics，Judge LLM 将从以下三个核心维度对 LLM Response 进行打分：核心现象捕获 (e.g., 核心物理现象): 模型是否精准识别了该反事实设定下被触发的核心学科原理（如极端相对论效应、基础经济学规律等）。宏观过程推演 (宏观过程推演): 评估模型是否能够基于初始条件，展开多层次、多阶段的宏观演化描述。逻辑连贯性与表达清晰度: 文本叙述的结构是否流畅，因果关系的表达是否清晰易懂。3. 结果评估指标 (OM: Outcome Metric) —— 结论一致性比对此指标作为条件分支，仅应用于封闭式问题（Closed Items）。对于推演链条最终会收敛于特定事实或科学定论的问题，系统会提取 LLM 回复的最终结论，并与预设的客观真值（GT: Ground Truth）进行一致性（Consistency）比对。总结： 通过将问题区分为 Open/Closed，并将评估解耦为结构化过程（PM）、定性量表（RM）和客观结果（OM），$What{-}if$ Bench 既能精准捕捉模型在复杂链路中的“逻辑断点”，又能兼容开放世界中因果推演的发散性与多样性，从而真正触及大语言模型因果推理能力的深层边界。
